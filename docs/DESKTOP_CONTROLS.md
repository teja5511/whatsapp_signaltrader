# Desktop Safety Controls & Modal Confirmation Dialogs

## Typed Phrase Modals
High-risk operations require explicit phrase input:
- Enable Demo Trading: `"ENABLE DEMO XAUUSD TRADING"`
- Emergency Stop: `"EMERGENCY STOP XAUUSD"`
- Reset Emergency Stop: `"RESET EMERGENCY STOP"`
- Emergency Close All: `"CLOSE ALL DEMO XAUUSD"`
- Reset WhatsApp Session: `"RESET WHATSAPP SESSION"`
